`third_party/rules/bus_rulebook.pdf` is 2 large sheets; the Read tool returns them as full text.
- RB p.1: Contents, Setting Up, First Buildings, First Bus Lines (+ asterisk exception), Phase 1, Phase 2 intro (resolution order, left-to-right, "as fully as possible", dwindling power, M), Line Expansion intro + Green/Purple/Blue M=3 example.
- RB p.2: Line Expansion rules 1–3 (5p +1, loops, unoccupied rule, exception "for 1 street"), Blue/Red/partial-loop/full-loop examples, Buses, Passengers, Buildings, Clock (steps 1–2), Vrrooomm! (conditions, examples 1–2), Starting Player + cleanup, End of the Game (tiebreaks).
